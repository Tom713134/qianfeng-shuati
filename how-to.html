前锋刷题软件

解压后整份文件夹留下，双击即可做题。不用安装，不用注册。

怎么打开

  1. 把整个文件夹放到电脑里（桌面或网盘都可以），不要只拷其中一个文件。
  2. 双击带图标的 前锋刷题 快捷方式。没有时先双击 start.bat 或 open.vbs，会自动生成快捷方式。
  3. 第一次会弹出独立窗口。关掉窗口即退出，不必关后台。
前锋刷题软件
选择题练习 · 进度保存在这台电脑

Windows 提示「已保护你的电脑」时

  1. 点「更多信息」，再点「仍要运行」。
  2. 或者：右键 start.bat / open.vbs → 属性 → 勾选「解除锁定」→ 确定。
  3. 从 QQ / 微信 / 网盘下载的压缩包常会带这个标记，解压后按上面做一次即可。

进度会保留

  • 做题记录、导入的题库、API Key 都存在这台电脑上，下次打开还在。
  • 不要删除 %APPDATA%\QianfengShuati，也不要清除「前锋刷题软件」窗口里的网站数据。
  • 换电脑时：打开「设置 → 题库设置 → 导出」，勾选完整备份，再选保存位置。到新电脑后用「设置 → 题库设置 → 导入」打开这份 JSON。

日常使用

  1. 侧边栏顶部可切换 刷题模式 / 考试模式。
  2. 刷题模式：点选项立刻显示对错和解析。侧边栏「题库」标题下可搜索本题库，也可用错题、收藏筛选。
  3. 题目卡片上可点「收藏」，之后在侧边栏只看收藏的题。
  4. 考试模式：选题库后点「开始考试」。答题中不显示答案，交卷后出分，并写入成绩档案，可随时回看。右键成绩可删除，档案页可全部清空。
  5. 侧边栏「载入示例题库」、打乱题序/选项、清空记录仍在原来的位置。
  6. 侧边栏点「设置」后，主界面是可折叠的「题库设置」和「API 设置」。点开后才显示导入、导出、编辑题目或填写接口。
  7. 可用「载入示例题库」，或把 questions/sample-questions.json、questions/sample-questions.txt 拖进窗口。课内试卷请留在本机，不要提交到仓库。
  8. 有自己的 API Key 时，在设置页的「API 设置」里填写，答完题后可生成解析。不填也能刷题。
