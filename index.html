导入

支持 JSON、CSV、Markdown 和文本，也可以导入本软件导出的备份文件。

查看格式说明

JSON：每题包含 question、options、answer、explanation。多选答案写成 BD。

{
  "name": "我的题库",
  "questions": [
    {
      "question": "题干",
      "options": ["选项一", "选项二", "选项三", "选项四"],
      "answer": "B",
      "explanation": "解析"
    }
  ]
}

文本或 Markdown：题目用 1. 2. 编号，或题目之间空一行。选项写成 A. / A)；答案写成 答案：B 或 **Answer: B**，写在选项后面同一行也可以。

1. 题干
A. 选项
B. 选项
**Answer: A**
解析：说明

CSV 第一行表头：question,A,B,C,D,answer,explanation
