前锋刷题软件

解压后整份文件夹留下，双击即可做题。不用安装，不用注册。

网页试用

  1. 打开 GitHub 仓库 About 里的 Website（GitHub Pages），浏览器里即可刷示例题。
  2. 网页版进度只存在当前浏览器。要导入自己的试卷，请用下面的 Windows 打开方式。

怎么打开

  1. 从 GitHub 下载 zip 或克隆本仓库，把整个文件夹放到电脑里，不要只拷其中一个文件。
  2. 双击带图标的 前锋刷题（快捷方式）。没有图标时，双击 打开前锋刷题.vbs 或 前锋刷题.bat。
  3. 第一次会弹出独立窗口。关掉窗口即退出，不必关后台。
前锋刷题软件
刷题 / 考试 · 进度保存在这台电脑

Windows 提示「已保护你的电脑」时

  1. 点「更多信息」，再点「仍要运行」。
  2. 或者：右键 打开前锋刷题.vbs / 前锋刷题.bat → 属性 → 勾选「解除锁定」→ 确定。
  3. 从 QQ / 微信 / 网盘下载的压缩包常会带这个标记，解压后按上面做一次即可。

进度会保留

  • 做题记录、导入的题库、API Key 都存在这台电脑上，下次打开还在。
  • 不要删除 %APPDATA%\前锋刷题软件，也不要清除「前锋刷题软件」窗口里的网站数据。
  • 换电脑时：把整个文件夹拷走，并在本软件里先「导出题库」。进度目前跟这台电脑绑定。

日常使用

  1. 侧边栏顶部可切换 刷题模式 / 考试模式。
  2. 刷题模式：点选项立刻显示对错和解析；做错的题用「只看错题」。
  3. 考试模式：选题库后点「开始考试」。答题中不显示答案，交卷后出分，错题记入错题本。可选题量、时限，并打乱题序或选项。
  4. 侧边栏「导入题库」，拖入 题库/sample-questions.json 或 题库/sample-questions.txt。也可导入自己的 JSON、Markdown、CSV 或文本。
  5. 课内试卷请留在本机，不要提交到仓库。
  6. 有自己的 API Key 时，可在「API 设置」里填写，答完题后生成解析。不填也能刷题。
